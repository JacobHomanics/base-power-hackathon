# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v57.0.0/ before writing any code.

This app uses the same Expo web shell as Bluebell Stock Exchange:

- React Navigation, with a native stack on iOS and Android and the JS stack on web (`RootStack.web.tsx`)
- App code in `src/`, imported with the `@/` alias
- Metro single-page web output (`expo export -p web`)

Use `npx expo install` for SDK-compatible packages. Run `pnpm web` for Expo web.
